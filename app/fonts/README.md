# Fonts

Self hosted, subset to basic Latin plus a few punctuation marks so they load fast.

| File | Source | License |
|---|---|---|
| `beth-ellen.woff2` | Beth Ellen, via @fontsource/beth-ellen 5.3.0 | SIL Open Font License 1.1 (`LICENSE-BethEllen.txt`) |
| `lora.woff2`, `lora-italic.woff2` | Lora variable, via @fontsource-variable/lora 5.3.0 | SIL Open Font License 1.1 (`LICENSE-Lora.txt`) |

Lora carries the Reserved Font Name "Lora", so the subset files are renamed internally to "Wild Hearts Serif" as the license requires for modified versions.

If a heading ever needs a character outside the subset (for example an accented letter in a new product name), rebuild the subset with fontTools including that character.
